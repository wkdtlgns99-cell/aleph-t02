   - 30초 내 보스 HP 0 도달 시 `🏆 [MISSION COMPLETE]` 오버레이와 승리 팡파르 사운드가 울리며, [다시 시작] 시 실드 100 / 시간 30.0s / 스코어 0으로 즉시 초기화됩니다.
