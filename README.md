3. **③ 무엇이 보이면 통과인가요**:

4. **④ 안 될 때 무엇이 보이나요**: 
   - 조작 버튼 클릭 시 반응이 없거나, 30초가 지나도 승패가 나지 않거나, 화면 가로 넘침이 발생해 버튼이 잘리거나, 브라우저 개발자 콘솔에 빨간 오류 메시지가 출력됩니다.
